# Network Basics - Basics 0

This repository contains introductory projects on networking concepts, protocols, and architecture models such as OSI and TCP/IP.

## Directory Structure

| Directory | Description |
| --- | --- |
| `basics_0` | Basic networking principles, OSI model layers, and protocols |

## Files Description

| File | Description |
| --- | --- |
| `0-OSI_model` | Answers to foundational questions about the OSI (Open Systems Interconnection) conceptual framework |

## Topics Covered

* **OSI Model Architecture:** Conceptual framework for standardizing network communication into 7 distinct layers (Physical to Application).
* **Transport Layer:** TCP and UDP protocols for end-to-end communication and data transfer reliability.
* **Network Layer:** IP (Internet Protocol) routing and ICMP diagnostics.

## Requirements

* All files are formatted according to the project specifications.
